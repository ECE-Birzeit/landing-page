ENCS4110 / GPIO

Driving the on-board LED

Set the pin direction, then flip a bit in the data register. Every block copies cleanly into your IDE.

blink.s
; Toggle the red LED on PF1
        LDR     R0, =GPIO_PORTF_DATA_R
        LDR     R1, [R0]
        EOR     R1, R1, #0x02
        STR     R1, [R0]

ENCS4101 / Timers & PWM

Dimming an LED with PWM

Start a timer channel in PWM mode, then change the duty cycle while the program runs.

main.c
/* Start PWM on TIM2, channel 1 */
HAL_TIM_PWM_Start(&htim2, TIM_CHANNEL_1);

/* duty: 0..999 maps to 0..100 % */
__HAL_TIM_SET_COMPARE(&htim2, TIM_CHANNEL_1, duty);

ENCS5150 / SQLite

Saving a record with SQLite

Open a writable database, fill a ContentValues row, insert it. The manual builds the helper class first.

StudentRepo.java
SQLiteDatabase db = helper.getWritableDatabase();
ContentValues row = new ContentValues();
row.put("name", name);
row.put("year", year);
db.insert("students", null, row);
